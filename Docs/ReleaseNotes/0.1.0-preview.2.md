# CueEngine / CueHub 0.1.0-preview.2

## CueHub

- 左側の「プロジェクト」「インストール」「設定」から画面を切り替える。
- 登録済み Project の一覧に名前・Engine Version・保存場所を表示する。
- 右上の「追加」から既存 Project を登録し、「新しいプロジェクト」から専用の作成ページへ進む。
- 作成する Engine は作成ページで選択する。テンプレート選択は削除し、空 Project を作成する。
- インストール済み Engine のカード、検索、正式版／Preview の絞り込み、各 Engine の管理メニューを追加する。
- 公開 Engine の選択は別ウィンドウで行う。
- 開発時は生成した Visual Studio Solution の CueHub を F5 で起動できる。

## CueEditor / SDK

- UI Font を Inter 18px、日本語 Fallback を Noto Sans JP に変更する。
- コード表示用に JetBrains Mono 16px、UI Icon 用に Material Symbols Outlined を登録する。
- Font と License を Editor の実行時資源と Source-backed SDK に含める。
- 実行 File 隣から Font を読み、CWD と Unicode 配置に依存しない。
- Font が不足する場合は初期化 Error を返す。
- 新しい Hub 操作と空 Project に合わせて導入ガイドを更新する。

## 配布条件

Windows x64 向けの Preview。Engine は Development 構成の Source-backed SDK。
ゲームの Build には Visual Studio 2026、Windows SDK、CMake 4.2 以上が必要。
署名付き Manifest と Hash で配布物を検証する。Authenticode 署名と別 PC での通し検証は未実施。
